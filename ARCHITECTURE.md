# Het Dhuran Special Needs Centre

The site is a public, single-page introduction to the centre in Jambiani, Zanzibar. It has no user accounts, roles, login flow, protected areas, donation form or stored user data.

## Page structure

- `app/page.tsx` contains the complete landing page: hero, centre overview, care and therapy services, and a phone contact call to action.
- `components/layout/header.tsx` provides in-page navigation.
- `components/layout/footer.tsx` repeats the page links and public contact details.
- `app/globals.css` contains the warm paper, ink, clay and forest palette and responsive landing page styles.
- `app/layout.tsx` provides the document metadata and shared header and footer.

The navigation uses section anchors so the complete visitor experience remains on the home page. The centre can be reached at +255 780 981 880.
