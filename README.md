# Dhuran Supporting Organization

A responsive Next.js homepage for Dhuran Supporting Organization, focused on
supporting children, community health, and women's health.

## Getting started

```bash
npm install
npm run dev
```

Visit [http://localhost:3000](http://localhost:3000).

The homepage is in `src/app/page.tsx`, with page styling in
`src/app/globals.css`. Local image assets are stored in `public/`.

## Production

```bash
npm run build
npm start
```
